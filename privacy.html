翻譯煎餃 Chrome 擴充功能

隱私權政策

最後更新：2026-09-24 ・ English summary

一句話版本

翻譯煎餃是 Chrome 桌面版擴充功能，使用你自己的 API 金鑰（BYOK）。你按下翻譯後，要翻的文字會從你的瀏覽器直接送到你選的 Gemini、OpenAI、Groq、DeepL 或 Google 翻譯官方 API。翻譯煎餃沒有自己的伺服器，沒有遙測、追蹤或廣告，也不販售任何資料。

什麼時候會送出資料

只在下面這些時候：

  • 你按「翻譯影片字幕」「翻譯目前網頁」，或按快捷鍵 Alt+T。
  • 整頁翻譯開著時，你反白文字後按「譯」或「查看原文」。
  • 你測試連線，或貼上金鑰後由擴充功能自動測試連線。
  • 你在同一個分頁、同一個網站再次打開擴充功能視窗時，會自動恢復你上次在這個分頁開著的翻譯。換到別的網站或關掉分頁就不會恢復。

Chrome 的本機儲存沒有加密。能登入你的作業系統帳號、或能讀取 Chrome 使用者資料夾的人，仍可能讀到這些資料。

怎麼刪除你的資料

  • API 金鑰：在擴充功能視窗清空金鑰欄。
  • 翻譯紀錄與錯誤紀錄：打開擴充功能視窗的「翻譯偏好」，按「清除翻譯紀錄」，再按一次確認。看到「已清除」就刪好了。
  • 錯誤紀錄：在擴充功能視窗按「知道了」。
  • 分頁翻譯狀態與分頁送出的字數：關掉分頁。
  • 全部資料（含翻譯紀錄）：到 chrome://extensions 移除翻譯煎餃，Chrome 會一併刪除它存的所有資料。
  • 已經送到服務商的資料：依各服務商的政策處理，請直接向服務商申請。

第三方服務商

五家都使用你自己的 API 金鑰。服務商可能收費、限制額度或保留請求紀錄，請一併查看它們的條款與隱私權政策。翻譯煎餃不代付、不轉售，也不控制第三方 API 額度。使用各服務商的 API 需符合它們的年齡與地區規定。

  • Google Gemini API：沒開帳單的免費額度屬於 Google 的免費服務。Google 會用你送出的內容和回應改進產品與模型，可能有人工審閱，Google 也要求不要送出敏感、機密或個人資料。想避免這件事，請替 API 專案開啟帳單，或改用其他服務商。
  • OpenAI API
  • Groq API
  • DeepL API：免費金鑰（以 :fx 結尾）送往 api-free.deepl.com，付費金鑰送往 api.deepl.com，判斷只在你的瀏覽器完成。免費方案不適用 DeepL Pro「不保存文字」的承諾，送出的文字可能被保存；DeepL 條款也限制用免費方案處理個人資料。
  • Google Cloud Translation API：Google 表示不會用你送出的內容訓練翻譯功能。

我們不做的事

  • 不收集瀏覽紀錄、網址清單、付款資料、使用統計或廣告識別碼。
  • 沒有自家伺服器，文字不經過任何中介服務。
  • 不販售、出租或轉讓使用者資料，也不把資料用在翻譯以外的用途。
  • 不擷取音訊、不啟動語音辨識，不要求麥克風或分頁音訊權限。
  • 不常駐在所有網頁；只有你按下翻譯後，程式才進入目前分頁。
  • 不在無痕視窗執行，無痕頁面的內容不會進入擴充功能的儲存空間。

Chrome 權限用途

  • storage：在本機保存設定、API 金鑰、資料揭露的同意紀錄、錯誤紀錄、分頁翻譯狀態與每個分頁送出的字數。
  • activeTab、scripting：你按下翻譯或 Alt+T 時，Chrome 暫時允許翻譯煎餃進入目前分頁，把翻譯程式放進去。YouTube、Coursera 和一般網頁上的字幕與文字，都是靠這兩個權限讀到的。
  • youtube.com、youtube-nocookie.com：只補一種情況，就是別的網站（例如部落格或課程頁）裡內嵌的 YouTube 播放器。它屬於另一個網域，上面的暫時權限進不去，需要這兩個網域的權限才能讀到字幕。同樣只在你按下翻譯後才執行，而且只讀字幕：向 YouTube 取字幕檔，或複製播放器已經下載的字幕檔。
  • Gemini、OpenAI、Groq、DeepL、Google 翻譯的 API 網域：背景服務只呼叫你選的那一家。

政策變更

這份政策有變動時，會更新上方的「最後更新」日期。送出的資料種類有變動時，會在擴充功能裡另外告知，並重新取得你的同意。

English summary

Translation Gyoza is a bring-your-own-key Chrome extension. When you click a translate button or press Alt+T, the text to be translated (video captions, visible page paragraphs, or the text you select) is sent directly from your browser to the provider you chose (Google Gemini, OpenAI, Groq, DeepL or Google Cloud Translation) using your own API key. Your API key is sent only to the provider you selected. For Gemini, OpenAI and Groq, the text around your selection, the page title, description, site name and your optional translation context and glossary are also included; DeepL and Google Cloud Translation receive only the text to translate. We run no server, collect no analytics, and never sell or share data. Your API keys, settings, your data disclosure consent record, a translation cache with the site origin of each entry, and the last error record stay in Chrome's local extension storage and are deleted when you remove the extension. Cache entries older than 30 days are no longer used and are deleted the next time the browser starts or you translate. Per-tab translation state and per-tab character counts (no text) are kept in session storage and cleared when you close the tab or the browser. You can clear the translation cache and the error record at any time from the extension window. Contact: hi@gyozalab.com.
